deepseek-web-bridge — 调试页

本地 OpenAI 兼容网关 + Playwright sidecar。运行 .\scripts\manage.ps1 -Action start 后使用本页自检。仅供学习交流。

先完成网页登录：/login 打开登录窗口（未登录时 chat 返回 503 gateway busy）

1) 健康检查




2) 模型列表






3) 非流式对话 (POST /v1/chat/completions)








4) curl 示例


# 健康检查
curl http://127.0.0.1:8080/health

# 模型列表
curl http://127.0.0.1:8080/v1/models -H "Authorization: Bearer sk-test-local-proxy-key"

# 非流式
curl http://127.0.0.1:8080/v1/chat/completions -H "Content-Type: application/json" -H "Authorization: Bearer sk-test-local-proxy-key" -d "{\"model\":\"deepseek-chat\",\"messages\":[{\"role\":\"user\",\"content\":\"你好\"}]}"

# 流式
curl -N http://127.0.0.1:8080/v1/chat/completions -H "Content-Type: application/json" -H "Authorization: Bearer sk-test-local-proxy-key" -d "{\"model\":\"deepseek-chat\",\"messages\":[{\"role\":\"user\",\"content\":\"你好\"}],\"stream\":true}"

# 登录状态
curl http://127.0.0.1:8080/login/status
